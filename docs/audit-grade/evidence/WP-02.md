## Implemented result

WP-02 adds an auditable boundary around the legacy Strategy Brain:

```text
versioned YAML contracts
  -> canonical contract/schema hashes
  -> immutable quality-gated data_snapshot_id
  -> experiment_id allocated before candidate generation
  -> content-addressed run/candidate/artifact/decision identities
  -> complete-set publication only
  -> deterministic read-only replay plan
```

The deployable entrypoint is now unambiguous:

```text
Docker CMD ["python", "main.py"]
  -> main.py imports legacy_main
  -> install(legacy) instruments _generate and _review
  -> main(request) delegates without changing responses or exceptions
```

`legacy_main.py` is an exact behavioral copy of the historical implementation.
Its normalized SHA-256 is
`0a7886382206553e71857020336fa71d828030019741841d79ce6a27dc6a6df3`.
`main_wp02.py` no longer exists, so persisted Cloud Run command/args cannot
bypass registry installation by selecting a second source file.

## Contracts and registry

Twelve contracts are versioned. Their frozen identities are:

```text
data_contract_version = audit-contracts-v1
contract_set_hash = 94613f94d09fe13f15682d2678a11d6f98faf4b88234c52dcf59d76d1ebf8a49
schema_snapshot_hash = f7dac8b63c1ead7e6294496417ed94ba87f411cd8293d0a09aa90a400a0e8b73
```

The registry tables are `audit_data_snapshots`, `audit_experiment_runs`,
`audit_experiment_candidates`, `audit_experiment_artifacts`, and
`audit_experiment_decisions`. Candidates remain `REGISTRY_PENDING` until their
complete experiment lineage is persisted, after which they may become
`BACKTEST_ONLY`. `production_change_allowed` is always false.

The replay tool validates snapshot publication and immutability, experiment
lineage, dependency/configuration locks, candidate identities, and result
checksums without writing data or contacting a broker.

## Entrypoint correction evidence

The wiring and container tests prove all of the following:

- `main.py` imports `legacy_main` and `experiment_registry_adapter.install`;
- `install(legacy)` executes before delegation to `legacy.main`;
- the wrapper does not catch exceptions or transform responses;
- `_generate` and `_review` remain in the frozen legacy implementation and are
  instrumented by the adapter;
- registry context, including `experiment_id`, is created before candidate
  generation;
- `production_change_allowed=false` remains enforced;
- `/healthz` and `/readyz` return before payload processing or generation;
- the image, container configuration, and PID 1 all use `python main.py`;
- the loaded entrypoint is `/app/main.py`, the legacy module is
  `/app/legacy_main.py`, and `/app/main_wp02.py` is absent;
- safe probes make only `GET /healthz` and `GET /readyz`, report
  `mutation_performed=false`, and do not call OpenAI or generate candidates.
